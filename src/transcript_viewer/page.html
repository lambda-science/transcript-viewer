Settings

Kept in ~/.transcript-viewer/config.json, readable only by you. Each is sent to its own service and nowhere else, and none is ever read back into this page. A token in your keychain or password manager is safer than one in a file — set the environment variable instead and leave the field empty.

Add transcripts

A file or folder

A log, a converted trajectory, a HAR, or an archive of them. Dragging onto the window does the same.

From a URL

A GitHub repository — whole, or one folder inside it — an S3 bucket or prefix, or a direct link to a single file.

S3 is read by running the aws CLI, so sign in with aws sso login --profile <name> first. The profile is worked out from your setup; only a machine with several needs one chosen, in Settings.
